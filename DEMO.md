# 🚀 GeminiOS - Quick Start Demo

## Okamžité spuštění

1. Otevřete `index.html` ve vašem prohlížeči
2. Získejte API klíč (zdarma):
   - **Gemini** (doporučeno): https://aistudio.google.com/apikey
   - **Claude**: https://console.anthropic.com/
   - **OpenAI**: https://platform.openai.com/api-keys

3. Zadejte API klíč do welcome screenu
4. Klikněte "Spustit OS"

## 🎯 Co vyzkoušet jako první

### 1. Vygenerujte si kalkulačku
- Otevřete **🚀 AI Launcher** (dvojklik na ikoně nebo přes Start menu)
- Zadejte: "Vytvořit kalkulačku s moderním designem"
- Klikněte "Generovat aplikaci s AI"
- AI vytvoří plně funkční kalkulačku!

### 2. Zkuste AI Terminal
- Otevřete **💻 AI Terminal**
- Zeptejte se AI na cokoli, např:
  - "Jak funguje JavaScript?"
  - "Vysvětli mi, co je to API"
  - "Napiš vtip"

### 3. AI Browser
- Otevřete **🌐 AI Browser**
- Zadejte: "Krásná landing page pro kavárnu"
- AI vygeneruje kompletní HTML stránku

### 4. Hrajte si s okny
- Táhněte okna za záhlaví
- Dvojklik na záhlaví = maximalizovat
- Žluté tlačítko = minimalizovat
- Zelené tlačítko = maximalizovat/obnovit
- Červené tlačítko = zavřít

## 🎨 Customizace

### Změna vzhledu
1. Otevřete **⚙️ Nastavení**
2. V sekci "Vzhled" změňte tapetu
3. Vyberte si: Gradient, Tmavá, nebo Světlá

### Změna AI providera
1. Otevřete **⚙️ Nastavení**
2. Vyberte jiného AI providera
3. Zadejte nový API klíč
4. Klikněte "Uložit nastavení"

## 🐛 Řešení problémů

### "API error" při generování
- Zkontrolujte, že máte platný API klíč
- Zkontrolujte internetové připojení
- Zkuste jiného AI providera

### Aplikace se negeneruje správně
- Zkuste přeformulovat prompt (buďte konkrétnější)
- Zkuste kratší prompt
- Některé složité aplikace mohou vyžadovat několik pokusů

### Okno se nezobrazuje
- Zkuste obnovit stránku (F5)
- Zkontrolujte konzoli prohlížeče (F12) pro chyby

## 🎉 Fun Facts

- Všechny aplikace běží 100% na klientu (žádný server!)
- API klíče jsou uloženy pouze ve vašem prohlížeči
- Můžete vygenerovat neomezeně aplikací (pozor na API limity)
- Celý OS je jen ~60 KB kódu
- Podporuje drag & drop, resize, minimize jako skutečný OS
- Obsahuje easter egg (Konami code: ⬆️⬆️⬇️⬇️⬅️➡️⬅️➡️ B A)
